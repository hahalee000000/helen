# /goal 命令集成测试计划

## 测试场景

### 1. 基本功能测试
- 输入: `/goal 写一个 Python 计算器`
- 期望: 
  - 前端显示 "🎯 目标 Pursue 中... 第 1/10 轮"
  - Agent 开始工作
  - 如果未完成，自动继续下一轮
  - 完成后显示 "✅ 目标完成" 和总结

### 2. 完成标记测试
- 输入: `/goal 简单的任务`
- 期望: Agent 在第一轮回复中包含 `[GOAL_COMPLETE]`，循环结束

### 3. 多轮迭代测试
- 输入: `/goal 实现一个完整的 HTTP 服务器，包含路由、中间件、错误处理和测试`
- 期望: 多轮迭代（3-5 轮），每轮显示进度

### 4. 最大迭代限制测试
- 输入: `/goal 一个不可能完成的任务`
- 期望: 达到 10 轮后显示 "⚠️ 达到最大迭代次数 (10)"

### 5. 中断测试
- 输入: `/goal 长时间任务`
- 操作: 在第二轮时点击停止按钮
- 期望: 任务中断，显示已完成的进度

## 手动测试步骤

1. 启动 WebUI: `helen agent`
2. 在聊天框输入 `/goal 写一个 Python 脚本，计算斐波那契数列的前 20 项`
3. 观察:
   - [ ] 前端显示进度提示
   - [ ] Agent 开始编写代码
   - [ ] 如果代码不完整，自动继续
   - [ ] 完成后显示总结
4. 检查 transcript 文件，确认所有迭代都被记录
