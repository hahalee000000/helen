# Helen 7 维质量评分规则

## 评分维度（每维 0-10 分）

### 1. 安全性 (Security)
- **10 分**：所有输入都经过验证；无注入风险；秘密值不硬编码
- **7-9 分**：关键输入有验证；少量低风险问题
- **4-6 分**：部分输入未验证；存在中等风险（如 shell_exec 拼接）
- **0-3 分**：大量未验证输入；eval/exec 使用；硬编码秘密

### 2. 正确性 (Correctness)
- **10 分**：逻辑无误；所有边界处理；错误码完整覆盖
- **7-9 分**：主路径正确；少量边界未处理
- **4-6 分**：主路径基本正确；明显逻辑缺陷或边界问题
- **0-3 分**：主路径有 bug；不处理错误情况

### 3. 可维护性 (Maintainability)
- **10 分**：命名清晰；函数 < 50 行；无死代码；无重复
- **7-9 分**：命名较好；少量函数偏长
- **4-6 分**：命名混乱；函数过长；有死代码或重复
- **0-3 分**：单字母变量；超长函数；大量死代码

### 4. 性能 (Performance)
- **10 分**：无不必要的循环/分配；算法复杂度合理
- **7-9 分**：基本高效；少量可优化空间
- **4-6 分**：有明显的性能问题（如 O(n²) 可改 O(n)）
- **0-3 分**：严重性能问题（如死循环、大量重复计算）

### 5. 可测试性 (Testability)
- **10 分**：所有 public 函数可独立测试；依赖注入清晰
- **7-9 分**：大部分可测试；少量全局状态依赖
- **4-6 分**：部分函数难以测试（紧耦合）
- **0-3 分**：难以测试（大量全局状态、副作用）

### 6. Helen 规范 (Helen Compliance)
- **10 分**：完全遵循 Helen 最佳实践；正确使用 load_skill
- **7-9 分**：基本遵循；少量不符合惯例的写法
- **4-6 分**：多处不符合 Helen 惯例（如使用 Python 风格）
- **0-3 分**：严重违反 Helen 规范（如使用已删除语法）

### 7. 文档 (Documentation)
- **10 分**：注释完整；接口说明清晰；有使用示例
- **7-9 分**：注释较完整；少量文档缺失
- **4-6 分**：注释稀疏；文档不完整
- **0-3 分**：无注释无文档

## 判定规则

| 条件 | 判定 |
|------|------|
| 语法错误（helen check 失败） | **FAIL**（所有维度 0 分，不进入评分） |
| 完整性检查失败（integrity gate） | **FAIL**（所有维度 0 分，附带 issues 列表） |
| 任一项 < 6.0 | **FAIL**（必须改进） |
| 总分 < 7.5 | **CONDITIONAL**（建议改进） |
| 总分 ≥ 7.5 且每项 ≥ 6.0 | **PASS** |
| 总分 ≥ 8.0 且每项 ≥ 7.0 | **PASS（优秀）** |

## 评分流程

1. **Gate 0 — 语法检查**：`helen check <file>` → 失败则 FAIL，不进入评分
2. **Gate 1 — 完整性检查**：`load_skill("helen-code-integrity")` → 失败则 FAIL，附带 issues
3. **Gate 2 — 7 维打分**：使用 `get_scores()` + `get_metrics()` 自动分析 + LLM 综合判断
4. **汇总**：计算 overall（加权平均或简单平均），输出 verdict 和详细报告

## 输出格式

```json
{
  "status": "success",
  "scores": {
    "security": 8.5,
    "correctness": 9.0,
    "maintainability": 8.0,
    "performance": 7.5,
    "testability": 8.0,
    "helen_compliance": 9.0,
    "documentation": 7.0,
    "overall": 8.1
  },
  "verdict": "PASS",
  "report": "详细质量报告..."
}
```

## 分数格式化

所有分数使用 `format_float(score, 1)` 格式化，保留一位小数。

## 常见问题清单

- **安全性**：shell_exec 字符串拼接（应用 list 构建）；eval/exec 使用；用户输入未验证
- **正确性**：未处理空列表/空字符串；数组越界；除零；类型不匹配
- **可维护性**：函数超过 50 行；变量命名不清晰；重复代码块
- **性能**：嵌套循环（O(n²)）；在循环内分配大对象；重复计算
- **可测试性**：全局状态依赖；函数副作用多；紧耦合
- **Helen 规范**：使用 `->` 返回类型（已删除）；使用 `append`（不存在）；使用 `not`/`and`/`or`（应用 `!`/`&&`/`||`）
- **文档**：函数无注释；参数无说明；无使用示例
